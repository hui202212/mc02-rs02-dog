# DM02 | 四足机器狗运动控制器

基于 `STM32H723` 的四足机器人控制固件。机器人采用平面五连杆腿部机构，
通过两路 FDCAN 控制 8 个 LZ 伺服电机，当前控制周期为 `1 kHz`。

这个仓库用于展示完整的嵌入式机器人控制工程：从 CubeMX 外设配置、设备驱动、
实时调度，到步态、轨迹、运动学和姿态补偿。项目仍在持续开发中，README 会明确
区分“已验证功能”和“规划功能”。

## 项目亮点

- 以 `TIM7` 为基准的 1 kHz 机器人控制循环。
- 四腿对角步态、站立/趴下/起立状态机、前后运动和原地转向。
- 平面五连杆 FK/IK，将足端轨迹转换为 8 个关节目标角。
- 三次轨迹规划、Mahony 姿态解算和机身姿态补偿接口。
- CAN 电机反馈健康检查、失联/过温/错误状态保护和统一撤防路径。
- 通过 `robot_io` 隔离应用/算法代码与 CAN 总线、电机 ID 等硬件细节。
- 离线检查工具覆盖电机映射、零位范围、工作空间和轨迹连续性。

## 控制链路

```text
PS2 遥控器 -> Application 状态机 -> Control 步态/轨迹/IK
           -> System robot_io -> LZ 协议 -> FDCAN -> 8 个伺服电机
BMI088 SPI -> 姿态解算/补偿 --------------------^  1 kHz 控制周期
```

## 软件架构

```text
Application/   机器人模式、动作编排和遥控策略
Control/       步态、足端轨迹、五连杆运动学、滤波和统一参数
System/        1 kHz 调度、电机服务、健康监测和 robot_io 接口
Platform/      BSP、FDCAN、SPI、BMI088、PS2 和 LZ 设备协议
Core/          STM32CubeMX 生成的启动及外设初始化代码
```

详细依赖关系和时序见 [ARCHITECTURE.md](ARCHITECTURE.md)，实机标定和上电流程见
[ROBOT_BRINGUP.md](ROBOT_BRINGUP.md)。

## 编译与验证

1. 使用 Keil MDK 打开 `MDK-ARM/dm02.uvprojx`，构建 `dm02` target。
2. 修改机械参数或步态参数后运行：

```powershell
python .\tools\verify_robot8.py
```

几何、电机映射和零位等配置集中在 `Control/robot_config.h`。当前工程使用
定时器驱动的裸机运行时，不是 FreeRTOS；LZ 电机内部的电流环、速度环、位置环、
FOC 和 SVPWM 不属于本仓库实现范围。

## 实机安全

首次上电必须架空机器人，逐台确认 CAN 映射、方向、零位和限位。生产配置默认关闭
标定、裸 CAN 诊断和大范围动作开关。任何一条腿出现方向错误、反馈异常或通信丢失，
应立即断电并按 [ROBOT_BRINGUP.md](ROBOT_BRINGUP.md) 重新检查。
