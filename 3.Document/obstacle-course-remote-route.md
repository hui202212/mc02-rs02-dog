# 新规则障碍赛遥控与路线

本说明只对应第二十五届新规则障碍赛。比赛顺序和方向不限，场地图公布后按
“最短空驶距离 + 先拿稳定分”调整路线；砂砾碎木坑和高墙不进入路线。

## 新生演示控制

- `START`：自适应起立/回到正常站立。
- `SELECT`：进入低姿；保持摇杆后自动开始演示高速步态，不需要再选模式。
- 左摇杆上下：前进/后退。
- 右摇杆左右：左转/右转，前进和后退时都可同时使用。
- `R1`：站稳、摇杆回中后，直接执行一次向前小跳。
- `三角`：站稳、摇杆回中后，执行一轮单腿抬脚律动。
- 动作执行中不要按其它按键；跳跃和律动完成后自动回到站立。

`L1`、`L2`、`R2`、叉键、圆圈、方块、方向键当前不分配演示功能，避免新生误触发比赛专用动作。
底层木桥、斜坡、T台代码仍保留在工程中，但本演示固件不从遥控器进入这些模式。

## 演示动作

R1向前小跳时 `state_watch=8`，阶段0~7为：

```text
0下蹲蓄力 -> 1等待八电机同步 -> 2向前蹬伸 -> 3腾空向前收脚
-> 4前方准备落地 -> 5压腿缓冲 -> 6缓冲停留 -> 7恢复站姿 -> 255结束
```

其中预压和蹬伸时四脚向狗尾方向推地，机身获得向前速度；腾空后四脚向狗头方向收，
所以这不是原地跳。`jump_abort_watch=1` 表示预压阶段八电机未同步，动作会停止并回站立。

三角律动时 `state_watch=9`，`simple_robot_dance_stage_watch` 为 `0~7`：

```text
右前 -> 左前 -> 右后 -> 左后 -> 左后 -> 右后 -> 左前 -> 右前
```

每次只抬一条腿约20mm，始终保持三条腿支撑；完成后自动回到站立。

## 演示顺序

1. 上电等待八个电机准备好，按 `START` 起立。
2. 推左摇杆前后、右摇杆左右，演示低姿行走和原地/联合转弯。
3. 摇杆回中，按 `R1` 演示一次向前小跳。
4. 跳跃落稳后按 `三角` 演示单腿协调律动。
5. 再按 `START` 可回到标准站立姿态。

L1理论满杆速度约 `54mm / 0.11s = 491mm/s`，约为旧版的2.01倍。障碍内不要一直满杆，
演示跳跃前必须回中两个摇杆，并确保狗前方有足够空地。L1后退默认不加自动纠偏，
右摇杆左/右在前进和后退时含义一致。

## 实机演示前检查

1. 先架空确认四腿方向、零位和电机反馈正常。
2. 平地先测试L1低速小摇杆，再测试满杆前后和转弯。
3. R1向前小跳第一次必须使用吊绳或保护人员，确认落点和缓冲正常。
4. 三角律动确认四脚始终保持三腿支撑，没有抖动或卡滞。
